# P18 R0 Findings — Joint Retention Hardware

**Date**: 2026-08-10
**Phase**: P18 — Joint retention hardware + COTS hinge mode

## Probes executed

### 1. Countersunk hole creation
- **API**: `cq.Workplane().hole(dia, depth)`
- **Result**: Works natively. Volume = 12450.91 mm³ for 50×50×5 plate with 5mm hole.
- **Note**: For countersunk heads, we'll use a cone cut (BRepPrimAPI_MakeCone) rather than relying on CadQuery's built-in countersink.

### 2. Housing sleeve generation (hollow box)
- **API**: `cq.Workplane().box()`, `.cut()` for boolean subtraction
- **Result**: Successfully created 12-face sleeve (outer box - inner void).
- **Key**: Side wall thickness = (outer_dim - inner_dim) / 2. Must ensure inner void is slightly shorter than outer to leave a bottom boss.

### 3. Bottom boss (integral cylinder)
- **API**: `cq.Workplane().union()` with cylinder
- **Result**: Union of box + cylinder works. Boss sits on bottom face.
- **Note**: Boss is threaded placeholder (M5_placeholder per schema) — never real thread geometry.

### 4. Countersink cone
- **API**: `BRepPrimAPI_MakeCone` or CadQuery `cylinder()` with calculated dimensions
- **Result**: Cone height = cone_radius × (hole_dia/2) / (cone_radius - hole_dia/2). For 82° included angle: radius=5.0, height=5.0.
- **Key**: Cone points down from plate top surface, cutting into the plate to form the countersink seat.

### 5. Surface normal extraction
- **API**: `BRepGProp_Face(face.wrapped)` + `Normal(U, V, pnt, normal)`
- **Result**: Returns gp_Vec with components (X, Y, Z). For XY face at Z=0.5, normal = (-1, 0, 0) — pointing along negative X (expected for a box face in CadQuery).
- **Key**: Must pass `face.wrapped` (TopoDS_Face), not CadQuery Face wrapper. U/V are parametric coordinates [0,1].

### 6. Cylindrical face axis extraction
- **API**: `BRepAdaptor_Surface(face.wrapped)` + `GetType()` + `Cylinder().Axis()`
- **Result**: Correctly identifies GeomAbs_Cylinder. Axis direction = (0, 0, 1) for XY-oriented cylinder.
- **Key**: For coaxiality check, compare Cylinder().Axis().Direction() and Cylinder().Location() between two cylindrical faces.

### 7. Bolt geometry (Z-bolt)
- **API**: `cq.Workplane().cylinder()` for head + shank, `.union()`
- **Result**: Countersunk bolt = head cylinder + shank cylinder. Volume = 1894.38 mm³ for M5-style bolt (head_dia=9, head_h=3, shank_dia=5, shank_h=15).
- **Key**: Z-bolt axis = global Z per schema (`bolt.axis: global_z`).

## Key findings summary

| API | Usage | Notes |
|-----|-------|-------|
| `BRepGProp_Face(face.wrapped)` | Surface normal extraction | Need TopoDS_Face, not CadQuery Face |
| `Normal(U, V, pnt, normal)` | Get normal at parametric point | U/V in [0,1], normal is gp_Vec by ref |
| `BRepAdaptor_Surface(face.wrapped)` | Surface type + axis extraction | Need TopoDS_Face |
| `GetType()` → GeomAbs_Cylinder | Identify cylindrical faces | Compare axis direction for coaxiality |
| `Cylinder().Axis()` | Get cylindrical axis | gp_Ax1 with Direction() and Location() |
| `cq.Workplane().hole()` | Create through-holes | Simple bore for clearance holes |
| `cq.Workplane().cylinder()` | Create cylindrical features | For boss, bolt, pin features |
| `cq.Workplane().union()` | Boolean union | For housing + boss, bolt head + shank |
| `cq.Workplane().cut()` | Boolean subtraction | For voids, tongue clearance holes |

## Conclusions

All required OCP/CadQuery APIs are available and functional. The main design
challenge is the **preload-path continuity** check: swept bolt-load column from
head seat to boss must intersect aluminum bodies only, never composite. This
requires:
1. Generating housing geometry as a CadQuery Compound
2. Sweeping a cylinder along the bolt axis from head seat to boss bottom
3. Checking that the sweep intersects only aluminum (housing) bodies, not
   composite (wing) bodies

Coaxiality is computed by comparing Cylinder().Axis() between all bore chain
cylindrical faces (lip countersink, housing bore, tongue hole, boss bore).
